# Coding Fortune Teller

A simple mobile app that gives you a coding fortune.

## What I made

- A home screen with a coding message and a button to reveal your fortune.
- A fortune screen with a message and a button to go back.
- Built with React Native and Expo.

## Start after cloning

1. Clone the repository:

   ```bash
   git clone <repository-url>
   ```

2. Open the project folder:

   ```bash
   cd mobile
   ```

3. Install the dependencies:

   ```bash
   npm install
   ```

4. Start Expo:

   ```bash
   npx expo start
   ```

## Run with Expo Go

1. Install **Expo Go** on your phone.
2. Run `npx expo start` in the project folder.
3. Scan the QR code shown in the terminal with Expo Go. Keep your phone and computer on the same Wi-Fi network.

## Run on an Android emulator

1. Install Android Studio and create and start an Android emulator.
2. In the project folder, run:

   ```bash
   npm run android
   ```

You can also run `npx expo start` and press `a` in the terminal to open the app in the running emulator.
